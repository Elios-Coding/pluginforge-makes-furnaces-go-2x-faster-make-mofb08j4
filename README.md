# FastFurnace

A Minecraft Paper plugin that allows you to speed up furnace smelting globally.

## Features
- Toggle fast smelting on or off.
- Set a custom speed multiplier (up to 1000x).
- Works with Furnaces, Blast Furnaces, and Smokers.

## Commands
- `/fastfurnace on` - Enables the speed boost.
- `/fastfurnace off` - Disables the speed boost.
- `/fastfurnace <number>` - Sets the speed multiplier (e.g., `/fastfurnace 5` for 5x speed).

## Build
Build using Maven:
```bash
mvn clean package
```
